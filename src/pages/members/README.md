# 멤버 관리 (MEM001~004)

- `/members`: 이름·학번 검색, 기수 필터, 현재 검색 결과 CSV 내보내기, 역할 변경, 강퇴
- `/members?dialog=invite`: 초대 링크 발급 및 복사 모달
- `/members?role=member`: 기존 역할 미리보기 규칙에 따른 접근 제한 화면
- 초대 링크는 현재 origin의 `/clubs/join?invite=DB-DLOG`로 연결한다.

세션에 선택된 동아리가 있으면 서버 멤버 목록을 조회하고, 역할 변경·강퇴·초대 링크를 API에 요청한다. 로컬 화면 미리보기는 샘플 멤버 데이터를 사용한다.

## 서버 연동 시 교체할 부분

- 멤버 관리 화면은 서버가 제공하는 목록 조회, 멤버 정보 수정, 역할 변경, 강퇴 기능을 노출한다. 정보 수정은 기수·직책·활동 상태만 변경하며, 이름·학번은 수정하지 않는다. 직접 등록 UI는 제공하지 않는다.
- `role` 쿼리는 화면 미리보기용이며 인증 수단이 아니다. 실제 사용자와 동아리 권한을 조회하고 서버에서 접근을 제한해야 한다.
- 초대 링크 발급과 참여는 현재 API에 연결되어 있다. 만료 시간은 기본 168시간을 요청한다.
- 멤버의 납부 상태는 임시로 `확인 필요`를 사용한다. 회비 API 응답이 추가되면 실제 상태로 교체한다.

## 확인

`npm run lint`, `npm run build`, `npm run test:members`

테스트는 검색·검증·CSV와 경로별 서버 렌더링을 확인한다. 브라우저에서의 클릭, 클립보드 권한, 반응형 시각 검증은 별도로 확인해야 한다.
