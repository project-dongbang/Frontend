# 멤버 관리 (MEM001~004)

- `/members`: 이름·학번 검색, 기수 필터, 현재 검색 결과 CSV 내보내기, 멤버 수정
- `/members?dialog=invite`: 초대 모달. 직접 등록 버튼으로 등록 모달 진입
- `/members?role=member`: 기존 역할 미리보기 규칙에 따른 접근 제한 화면
- 초대 링크는 현재 origin의 `/clubs/join?invite=DB-DLOG`로 연결한다.

기존 페이지와 동일하게 샘플 데이터와 React 상태를 사용한다. 새로고침하거나 다른 페이지로 이동 후 돌아오면 등록·수정 내용은 초기화된다. 검색·통계는 64명의 샘플 레코드에서 계산한다.

## 서버 연동 시 교체할 부분

- `membersMock.ts`의 동아리·멤버·초대 정보를 실제 API 응답으로 대체한다.
- 목록 조회, 등록, 수정과 중복 학번·마지막 활동 회장 검증을 서버에서도 처리한다.
- `role` 쿼리는 화면 미리보기용이며 인증 수단이 아니다. 실제 사용자와 동아리 권한을 조회하고 서버에서 접근을 제한해야 한다.
- 초대 코드·링크의 발급, 유효기간, 취소 및 참여 유효성 검증은 서버 명세에 맞춰 연결한다. 현재 참여 화면은 기존 샘플 동작을 유지한다.
- 새 멤버의 납부 상태는 임시로 `확인 필요`를 사용한다. 회비 API의 기본 상태 정책과 연결하고 수정 폼에서는 변경하지 않는다.
- 활동 상태 선택지(`활동`, `휴면`, `탈퇴`)는 서버 명세와 대조한다.

## 확인

`npm run lint`, `npm run build`, `npm run test:members`

테스트는 검색·검증·CSV와 경로별 서버 렌더링을 확인한다. 브라우저에서의 클릭, 클립보드 권한, 반응형 시각 검증은 별도로 확인해야 한다.
