# 멤버 관리

- `/members`: 선택한 동아리의 서버 멤버 목록을 조회한다.
- 이름·학번 검색과 기수 필터는 조회된 멤버에 적용한다.
- 운영진은 기수·직책·활동 상태를 수정하고, 역할 변경·강퇴·초대 링크 발급을 API로 처리한다.
- 초대 링크는 서버가 발급한 토큰을 현재 origin의 `/clubs/join?invite=<token>`에 넣는다. 발급 전에는 링크를 표시하지 않는다.
- 일반 회원의 관리 화면 접근 여부는 세션의 동아리 역할로 결정하며, 서버가 요청마다 권한을 검증한다.
- 멤버 목록 API에는 납부 상태가 없으므로 목록에는 `확인 필요`로 표시한다.
